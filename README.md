# CAA PDF Extractor — database baseline

Generated from the Retool Database schema exports supplied on 2026-10-04.

## Included Retool tables

- case
- clinical_history
- examinations
- family_history
- laboratory
- medications
- radiology
- states

Retool-specific user-management/sample tables are intentionally excluded.

## Added provenance tables

- source_documents
- extraction_runs

## Important compatibility notes

1. Existing Retool enum values are preserved verbatim, including empty-string
   values in `gender_enum_5ac919f3` and `rx_mode_enum_565bcb50`.
2. Sequence-backed integer primary keys from Retool are represented as modern
   PostgreSQL `GENERATED BY DEFAULT AS IDENTITY` columns. This still permits
   explicit IDs when migrating existing data.
3. Existing nullable/default behavior is preserved as closely as possible.
4. Foreign-key indexes were added for `case_id` columns as a performance
   improvement; they were not explicitly present in the supplied constraint export.
5. No patient data are included.

## Windows setup

Create a PostgreSQL database and user, then copy `.env.example` to `.env` and
set the password.

Example SQL run as a PostgreSQL administrator:

```sql
CREATE ROLE caa_user WITH LOGIN PASSWORD 'choose-a-strong-password';
CREATE DATABASE caa_database OWNER caa_user;
```

Python environment:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
$env:PYTHONPATH = "$PWD\src"
```

Apply the database schema using Alembic:

```powershell
alembic upgrade head
```

Alternative: apply `schema.sql` directly using pgAdmin Query Tool or psql.
